# Akhil Biju — Product & Systems Designer Portfolio

> Calm, high-fidelity portfolio featuring bespoke enterprise UX case studies, interactive canvas physics, and modular design systems.

## ✨ Highlights

- **Bespoke Case Studies**:
  - **ShiftPartner (B2B SaaS)**: Cognitive load reduction for enterprise nurse roster management and on-call rotations with sub-minute shift claiming.
  - **SmartSlots (Enterprise AI Scheduling)**: Deterministic calendar rules, friction audit, and dual-mode dispatch workflows.
  - **Casey AI (Healthcare Chat Companion)**: Voice-first triage, conversational empathy protocols, and safety fallback UI.
  - **Tachyon Leap (FinTech)**: Multi-leg high-frequency asset transfer and risk mitigation visual flows.
- **Interactive Companion ("Rumaru")**:
  - Free-dragging jelly physics with spring return damping, dynamic eye tracking, squash & stretch deformation, and reactive conversational popups.
- **Design System & Craft**:
  - Deep calm ocean blue palette (`#0B132B`, `#1C2541`, `#3A506B`, `#48CAE4`).
  - Tactile typography and glassmorphic micro-surfaces.
  - Verified official vector tool stack (Google Antigravity, Claude, Affinity Designer, OpenAI ChatGPT, Figma, Android Studio, HTML/CSS).
- **Responsive Architecture**:
  - Full mobile, tablet, and desktop adaptive layouts.
